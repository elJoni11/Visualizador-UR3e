TCP/IP Industrial UR3e e-Series PolyScope 5 PyBullet Digital Twin

Visualizador y Control Remoto UR3e

Sistema modular multihilo para adquisición de telemetría cinemática (10 Hz / 500 Hz), sincronización con gemelo digital 3D y control supervisor en lazo cerrado con URScript.

1. Preparación del Entorno

Se requiere Python 3.9 o superior y el gestor de paquetes pip:

  1. Crear y activar el entorno virtual aislado:
    # En Windows: python -m venv venv venv\Scripts\activate # En Linux / macOS: python3 -m venv venv source venv/bin/activate
  2. Instalar la rueda oficial del simulador:
    pip install ur3e_rg2-0.1.0-py3-none-any.whl

2. Configuración Centralizada (robots.json)

Todos los scripts leen dinámicamente este fichero como única fuente de verdad, evitando modificar el código fuente entre el aula y el laboratorio:

Módulos del Sistema por Niveles

primaria.py

Puerto 30001 · 10 Hz

Cliente multihilo para la Interfaz Primaria. Decodifica el mensaje general de estado (Tipo 16) navegando por subpaquetes jerárquicos (TLV).

  • Subpaquete 0: Extrae parada de seguridad y estado de emergencia.
  • Subpaquete 1: Desempaqueta los 6 ángulos reales q_actual.
  • Gráficos: Bucle desacoplado a 60 FPS con threading.Lock.
python primaria.py

tiempo_real.py

Puerto 30003 · 500 Hz

Cliente de alta frecuencia para la Interfaz de Tiempo Real. Lee paquetes de estructura estática y posiciones fijas en bytes.

  • Offset 252: >6d (48 bytes con los ángulos articulares).
  • Offset 756 / 764: Modos de operación y seguridad.
  • Rate-Limiter: Absorbe a 500 Hz y refresca la UI a 60 Hz.
python tiempo_real.py

multirobot.py

Notable · Multi-Conexión

Visualizador concurrente capaz de representar múltiples brazos en la misma escena de PyBullet sin bloqueos mutuos.

  • Hilo trabajador por robot: Máquina de estados independiente.
  • Tolerancia a caídas: Si un robot cae, el resto sigue operando.
  • Polimorfismo: Soporta interfaces 30001 y 30003 simultáneamente.
python multirobot.py

enviar_ordenes.py (Nivel Sobresaliente: Teach & Playback)

Aplicación de control industrial en lazo cerrado que interactúa bidireccionalmente con el controlador UR3e:

Características de Seguridad

  • Arquitectura One-Shot: Conexión efímera dedicada para comandos URScript, reseteando la sesión del compilador y eliminando la excepción de subtipo 6.
  • Límite angular defensivo: Comprueba que ningún valor exceda $|2\pi|\text{ rad}$ para impedir giros accidentales por confusión con grados.
  • Monitoreo de emergencia: Parada inmediata ante isProtectiveStopped, seta física pulsada o errores de runtime de tipo 20.

Lazo Cerrado de Control

  • Confirmación de inicio: Supervisa la transición a isProgramRunning == True tras el envío del script.
  • Criterio de parada: Espera al retorno a False y evalúa que el error final sea $\max |q_{\text{act}} - q_{\text{obj}}| < 0.01\text{ rad}$.
  • Modo Freedrive: Permite enseñar posturas moviendo el robot físico manualmente (Modo Backdrive / 6).
python enviar_ordenes.py
